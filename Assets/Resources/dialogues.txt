# ============================================================
# CONTENT HOUSE - DIALOGUES (conversations with reply choices)
#
# Format - one [section] per conversation, lines in order:
#
#   line: <text>                     the other person speaks
#   choice: <A> | <B> | <C>          your reply options (2-3, ' | ' separated)
#   reply: <re A> | <re B> | <re C>  OPTIONAL, right after a choice: how the other
#                                    person reacts to each option, in the same order.
#                                    Use "-" for "no reaction" on an option.
#
# Flow: the other person's line -> you pick -> your pick is shown as your line ->
# their reaction (if any) -> the next 'line:'.
# Nothing advances on its own: the player presses [Space]/[Enter]/[E] or clicks.
#
# Tokens {player} {streamer} {friend} {intruder} are replaced live.
# Keep a line under ~220 characters so it fits the box.
#
# STORY RULES (so the early game stays a mystery):
#   - never name the Manager's workplace
#   - never mention a subathon / what is coming; the big event lands on an unpredictable day
#   - the odd viewers, the "last guy", the package: hints only, never explained
# ============================================================
