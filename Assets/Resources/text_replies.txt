# ============================================================
# CONTENT HOUSE - SECRET TEXT REPLIES (easter eggs)
#
# The player can type any text to Mr. IG or the Manager in the phone's Messages app.
# Nobody answers - EXCEPT when a message matches one of the rules below. Edit freely.
#
#   [rule_name]
#   to: ig | manager | any          who must have received the text
#   any: phrase | phrase | ...      a condition: at least one phrase must appear (whole words)
#   also: phrase | phrase | ...     OPTIONAL, belongs to the 'any:' above it: ALSO needs one of these
#   any: ...                        another 'any:' line = another way to trigger the same rule (OR)
#   reply: text | text | text       what they answer; the 1st reply is used the first time,
#                                   later triggers pick randomly among them
#   chance: 0.55                    OPTIONAL, 0-1, how often they bother to answer (default 1)
#   max: 2                          OPTIONAL, total replies this rule can ever give (default 2)
#   cooldown: 45                    OPTIONAL, seconds before this rule can answer again (default 45)
#   delay: 2-4                      OPTIONAL, seconds before the reply arrives (default 2-4)
#
# Matching ignores case and punctuation ("You're a LEGEND!!" = "youre a legend").
# Anti-spam (always on): repeating the same text is ignored for 2 minutes, there is a pause between
# any two secret replies, and every rule has its own max + cooldown. It is meant to be FOUND, not farmed.
# ============================================================
